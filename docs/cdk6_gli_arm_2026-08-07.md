# CDK6 as the second arm of the EZH2 mitogen-drive governor (2026-08-07)

**JP direction:** step back to the core story — *EZH2⊣CyclinD1 raises the mitogen threshold, so for vismo to arrest
MB the EZH2 axis must be intact* — and keep it simple. Add the one big MB-specific difference: the **massive CDK6
increase**, which is **Gli-driven** (JCI 2017) and **EZH2-marked**. Then (later) variable GNP G1 by mitogen dose and
periodic high-p27 transient G0. This doc covers #1 (CDK6). Standing rule respected: **default OFF, 30/32 preserved.**

## Data (JP's `p27_ratio_tiers_results.csv`, P7 wt GNP → SHH-MB)
- **Cdk6: 1508 → 26003 = 17.2×** — the biggest fold in the whole drive panel (LRT padj 8e-32). Ccnd1 7.6×, Ccnd2
  2.4×, Cdk4 2.1×, Mycn 2.9×. GNP is CDK4-dominated (Cdk4 10k ≫ Cdk6 1.5k); MB is CDK6-co-dominant (26k ≈ 21k).
- **Hh/Gli-driven:** ramps with drive (P7 wt 1508 → P28-Ptch 11463 → MB 26003); **vismo-sensitive** (MB→MB+V 0.41×,
  padj 0.033; wt GNP crushed to 0.20× under vismo, padj 2e-7). Active mark (H3K4me3) MB-high (log2FC +2.3–3.8).
- Paper: **Hedgehog signaling drives medulloblastoma growth via CDK6** (JCI 2017, PMID 29202464) — Hh → GLI2 binds
  the *Cdk6* promoter → CDK6 up → proliferation; CDK6 inhibition represses Hh-MB.

## Implementation (`with_cdk6_gli`, default OFF; harness `CDK6_GLI=1`)
CDK6 enters as a **Gli-driven, EZH2-marked multiplier `cdk6` on the CyclinD-CDK4/6→Rb Vmax** (`kPhRbCd*cdk6*(Cd+…)`,
both two-step-Rb reactions; the CyclinE/A-CDK2 arms `kPhRbCe/kPhRbCa` are untouched). It mirrors the CyclinD1 IFFL:
```
cdk6 := cdk6_basal + cdk6_Gli*(Gli_act+Gli1)^n /(K_Gli_cdk6^n + (Gli_act+Gli1)^n) * (K_EZH2_cdk6/(K_EZH2_cdk6 + EZH2*(1-EZH2i)))
```
Params: `cdk6_basal 0.3, cdk6_Gli 2.7, K_Gli_cdk6 0.3, n 2, K_EZH2_cdk6 8.0`. The EZH2 factor is deliberately **mild**
(large K) — a broad mark tunes *kinetics/threshold*, not steady-state magnitude, so the Gli drive (which dominates in
MB) is preserved (JP's H3K27me3-kinetics principle). Normalized so **GNP cdk6 ≈ 1** (GNP drive unchanged).

Operating values (Gli_act+Gli1 / EZH2): GNP 0.21/2.2, MB 0.40/4.5, vismo 0.0/1.5, +EZH2i raises EZH2. Resulting cdk6:
| condition | cdk6 | vs data |
|---|---|---|
| GNP | 1.00 | normalized |
| MB | 1.40 | modest functional boost (kinase saturates; not the raw 17× RNA) |
| MB+vismo | 0.30 (0.21× of MB) | data 0.41× (same direction, strong) |
| MB+EZH2i | 2.03 (1.45× of MB) | de-repression |

## Results
- **Validation: 31/32 out of the box** with the CDK6 arm on (no re-optimization) — one *better* than the 30/32
  default; fails only the same structural MB-HU-G2. Shh-dependence intact (GNP−SHH/+HHi/serum and MB+CDK4/6i all
  arrest), CyclinD1 MB/GNP 4.18, period 17.6 h, MB 24.4 h. Default (flag off) still 30/32.
- **Two-pronged governor (`cdk6_twoarm.py`):** the CyclinD-CDK4/6 drive proxy (Cd·cdk6) —
  | | MB | MB+vismo | MB+vismo+EZH2i |
  |---|---|---|---|
  | CDK6 OFF (1-arm) | 5.99 | 0.28 (4.7%) | 0.47 |
  | CDK6 ON (2-arm) | 8.15 | **0.08 (0.98%)** | 0.14 |
  Vismo collapses the drive **~5× deeper** with CDK6 on (both CyclinD1 and CDK6 fall) → **stronger vismo-dependence**,
  directly supporting "for vismo to arrest, the EZH2 axis must be intact." Under *full* vismo, EZH2i gives **no
  rescue** (Gli=0 → nothing to de-repress) — matches the validated `MB+…+EZH2i no rescue` target. At baseline (Gli
  present) EZH2i de-represses **both** arms (cdk6 1.45× + CyclinD1 ~1.5×) → a stronger two-pronged governor and the
  cleaner EZH2i→resistance prediction.

## What this buys the story
EZH2 now governs **both** components of the CyclinD-CDK4/6 module (the cyclin *and* its kinase), both Gli-driven and
both massively up in MB. That (a) makes MB's proliferative drive mechanistic (two Gli/EZH2 amplifiers), (b) makes
vismo a sharper two-arm hit on an intact axis, and (c) strengthens the EZH2i→vismo-resistance prediction — all while
keeping the model simple and *improving* validation (31/32).
